# primejersey.il — האתר בלי Shopify

עותק של החנות `primejersey.il` כאתר סטטי: אותו עיצוב, 380 המוצרים הפעילים ו־19 הקטגוריות.
אפשר לארח אותו בחינם (GitHub Pages / Netlify / Cloudflare Pages). אין דמי מנוי.

## איך הזמנה עובדת עכשיו

1. הלקוח בוחר מידה, פאץ׳, שרוול, שם ומספר, בדיוק כמו קודם.
2. בעגלה הוא ממלא שם, טלפון וכתובת ולוחץ **"שליחת ההזמנה בוואטסאפ"**.
3. נפתח וואטסאפ עם הודעה מוכנה לכם (052-8825211) שכוללת את כל הפריטים, הכמויות, המחיר והכתובת.
4. אתם שולחים ללקוח פרטי תשלום (Bit / PayBox / העברה).

מבצע **3+1 מתנה** עובד כמו בשופיפיי: מ־4 פריטים מהקטגוריות שהיו במבצע, הזול ביותר חינם (פעם אחת בהזמנה).

## לפני שמבטלים את Shopify — חובה

1. **להוריד את התמונות.** כרגע התמונות נטענות מהשרתים של Shopify, והן ייעלמו כשהחנות תיסגר.
   במחשב שלכם, מתוך תיקיית הפרויקט:
   ```
   python3 tools/download_images.py
   ```
   הסקריפט מוריד הכול לתיקייה `assets/img/`, ומעדכן את האתר לטעון מהעותק המקומי. אם חלק מההורדות נכשלו, פשוט מריצים אותו שוב.
   אחר כך עושים commit ו־push לשינויים.
2. **לייצא הזמנות ולקוחות** מתוך ממשק הניהול של Shopify (Orders → Export, Customers → Export). המידע הזה לא נמצא כאן.
3. **דומיין:** אם קניתם דומיין דרך Shopify, צריך להעביר אותו לספק אחר לפני הסגירה. הכתובת `4ynmhe-pk.myshopify.com` תפסיק לעבוד.

## להעלות את האתר לאוויר (GitHub Pages)

1. ב־GitHub: Settings → Pages.
2. Source: `Deploy from a branch`, בוחרים את הענף ואת התיקייה `/ (root)`.
3. אחרי דקה האתר זמין בכתובת שמופיעה שם. אפשר לחבר דומיין משלכם באותו מסך.

לבדיקה במחשב: `python3 -m http.server` ואז לפתוח את `http://localhost:8000`.

## מה שונה מ־Shopify

- **אין סליקה באתר.** התשלום מתואם בוואטסאפ (כמו הזמנות Bit שכבר עשיתם).
- **אין ניהול מלאי ואין מעקב הזמנות.** ההזמנות מגיעות כהודעות וואטסאפ.
- 33 מוצרים שהיו בטיוטה (Draft) לא מוצגים, כמו בשופיפיי. הם שמורים ב־`export/`.
- מיסטרי בוקס, NIKE MIND וחליפות אימון מוצגים בעמוד המוצר הרגיל (בשופיפיי היה להם עיצוב עמוד משלהם). כל האפשרויות והמחירים שלהם זהים.
- כתובות העמודים השתנו (למשל `#/products/...` במקום `/products/...`), כך שקישורים ישנים מגוגל או מאינסטגרם לא יובילו למוצר עצמו.

## מה יש בתיקיות

- `index.html`, `assets/`, `data/catalog.json` — האתר עצמו.
- `export/` — גיבוי מלא של כל המוצרים (כולל טיוטות), הקטגוריות וקוד העיצוב המקורי מ־Shopify.
- `tools/` — סקריפטים: בניית הקטלוג, חילוץ העיצוב, הורדת התמונות.
